Sistema de diseño

Tres paletas y tres paquetes tipográficos

Una base visual limpia, cercana y seria para presentar Un colegio: Muchas voces y sus candidaturas nacionales y regionales. Elige una paleta y un paquete de fuentes; todas las combinaciones usan los mismos componentes y están pensadas para mantener buen contraste y legibilidad.

Color

Tres paletas con la misma intención

Cada paleta define tinta, primario, acento, fondos y líneas. Los acentos aparecen solo en detalles —reglas, píldoras, cifras— para que el conjunto se lea tranquilo y confiable.

Implementación

Cómo aplicar una combinación

Todo el sistema vive en variables CSS. Cambiar de paleta o de fuentes no exige tocar los componentes: basta con dos atributos en la etiqueta <html>.

Dos atributos, nueve combinaciones

El sitio se entrega con Paleta 1 y Paquete A activos. Las demás opciones están cargadas y se pueden previsualizar añadiendo ?paleta=2 o ?fuentes=b a la dirección.

Para dejar una combinación como definitiva, edita los atributos de <html> en index.html. Si más adelante quieres eliminar las fuentes que no uses, ajusta el enlace de Google Fonts y la hoja de estilos.

<!-- Combinación activa -->
<html lang="es-CL" data-palette="1" data-fonts="a">

/* styles.css */
:root {
  --primary: #1f4e6b;
  --accent:  #b45f33;
  --bg:      #f8f5ef;
}
